# 🎮 Tic Tac Toe Game  

🕹️ A lightweight and interactive **Tic Tac Toe** game for two players, built to sharpen coding and logic skills. 👨‍💻  

---

## 📝 Problem Statement  
Classic games like Tic Tac Toe are simple but powerful for learning **front-end development**. This project addresses the need for a **beginner-friendly yet engaging game** to practice **DOM manipulation, event handling, and game logic implementation**.  

---

## 📊 Current Progress Status  
- ✅ Basic 3x3 Tic Tac Toe board implemented  
- ✅ Player turns (O & X) handled with toggle logic  
- ✅ Winner detection using winning patterns  
- ✅ "Congratulations" winner message with replay option  
- ✅ Reset & New Game functionality  
- ⏳ Pending: Scoreboard, AI-based opponent, improved responsiveness  

---

## 💡 Solution / Prototype  
This project:  
- 👥 Enables **two-player gameplay** on the same device  
- 🔎 Uses **predefined win patterns** to check results dynamically  
- 🎉 Displays a **winner message** when a player wins  
- 🔄 Allows players to **reset or start a new game** anytime  

---

## 🛠️ Technologies & Tools Used  
- 🌐 **HTML5** – for structure  
- 🎨 **CSS3** – for styling and responsiveness  
- ⚡ **JavaScript (Vanilla)** – for game logic and interactivity
